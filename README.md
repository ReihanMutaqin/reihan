## 📌 Ringkasan

Portofolio ini menampilkan profil profesional, portofolio karya terpilih, riwayat pengalaman kerja & organisasi, keahlian teknis, serta tautan langsung untuk mengunduh CV ATS (PDF & DOCX) dan menghubungi secara langsung.

### 🌟 Fitur Utama
- **Desain Editorial & Minimalis**: Tipografi kuat, palet warna elegan (`#f3efe5` paper, `#151515` ink, aksen `#f2c94c` & `#e95d32`), dan tata letak responsif.
- **Navigasi Mulus**: Menu navigasi desktop & seluler dengan penanda interaktif dan dukungan aksesibilitas (skip-to-content, keyboard focus visible).
- **Showcase Karya / Proyek**: Daftar proyek interaktif (AR Book, Game Edukasi, Portal Berita, E-Commerce, dsb.) lengkap dengan tag teknologi dan tautan langsung.
- **Pengalaman & Keahlian**: Struktur riwayat karier di industri telekomunikasi (PT Telkom Indonesia), pengajaran, dan proyek freelance.
- **Unduh CV ATS Terintegrasi**: Tautan langsung untuk mengunduh berkas CV ATS resmi format PDF dan Microsoft Word (.docx).
- **Saluran Kontak Terintegrasi**: Akses cepat via Email, WhatsApp / Telepon, GitHub, dan LinkedIn.

## 🚀 Memulai Proyek Secara Lokal

### Prasyarat
- [Node.js](https://nodejs.org/) (versi 18 ke atas disarankan)
- `npm` atau `pnpm` / `yarn`

### Instalasi & Menjalankan

1. **Clone repositori**:
   ```bash
   git clone https://github.com/ReihanMutaqin/reihan.git
   cd reihan
   ```

2. **Instal dependensi**:
   ```bash
   npm install
   ```

3. **Jalankan server pengembangan**:
   ```bash
   npm run dev
   ```

4. **Build untuk produksi**:
   ```bash
   npm run build
   ```

5. **Jalankan pengecekan lint**:
   ```bash
   npm run lint
   ```
